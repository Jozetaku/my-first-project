# Wooden Cursor 50px Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Increase the approved wooden-tool cursor from 42px to exactly 50px on desktop and mobile without changing the rings or cursor behavior.

**Architecture:** Preserve the existing single cursor component in `index.html`. Tighten its source-contract test first, then make the minimum CSS-only dimension change and publish the resulting `main` commit through the existing GitHub Pages workflow.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, Node.js built-in test runner, Git, GitHub Pages

## Global Constraints

- The wooden cursor container is exactly `50px` by `50px` at every viewport size.
- The supplied PNG and its aspect ratio remain unchanged.
- Inner and outer ring sizes, breathing animation, colors, opacity, and interactive green state remain unchanged.
- Desktop tracking and mobile touch-follow behavior remain unchanged, including the 30px vertical offset and 500ms fade.
- Native cursors remain suppressed over interactive elements.
